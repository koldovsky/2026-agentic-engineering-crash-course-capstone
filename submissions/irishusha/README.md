# Agentic Planning Poker

Невеликий локальний Planning Poker, проведений через повний agentic engineering цикл: контекстні правила, специфікації наперед, red/green тести, єдиний verification gate та незалежний reviewer-субагент.

- **Код:** [Irishusha/agentic-planning-poker](https://github.com/Irishusha/agentic-planning-poker)
- **Live demo:** [agentic-planning-poker.vercel.app](https://agentic-planning-poker.vercel.app/)
- **Video demo:** (https://www.loom.com/share/0a0f40e74ef34174bfd1efe98ad33f74)
- **Capstone evidence:** [docs/capstone-evidence.md](https://github.com/Irishusha/agentic-planning-poker/blob/main/docs/capstone-evidence.md)
- **CI:** [успішний GitHub Actions run](https://github.com/Irishusha/agentic-planning-poker/actions/runs/36242302280)

Продукт дозволяє налаштувати задачу та команду, проголосувати оцінками по ролях, приховати голоси до Reveal, побачити Overall і per-role статистику, повторити оцінювання або перейти до наступної задачі зі збереженням команди.
