# Андрій Кутіль — method-sync-v2

Код і вся історія розробки — в окремому репозиторії: https://github.com/akutil/method-sync-v2

CLI, що тримає Java-бібліотеку біржового конектора (Binance USDⓈ-M Futures) в синхроні з живим API біржі: знаходить
поля DTO, яких бракує або які зайві, і значення енамів, яких бракує, і жене `claude -p` у циклі до зеленої перевірки.
Побудовано агентно в Claude Code з Project Factory: вимоги й специфікації OpenSpec до коду, тести першими,
рецензія окремими агентами, журнал рівнів довіри.

Опис практик із доказами, відео і що вирішував я, а що агент — в описі PR.
