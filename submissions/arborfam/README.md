# CX Process Agents — AI-пайплайн для процесного аналітика

Прототип допомагає процесному аналітику перетворювати вихідні матеріали на структурований опис AS-IS, виявляти прогалини та готувати BPMN-схему після перевірки опису людиною.

Демонстраційний кейс — процес підготовки та передачі інформації про продуктові зміни операторам колл-центру.

## Логіка роботи

1. Аналітик додає джерела з інформацією про процес.
2. Перший агент формує чернетку AS-IS та підсвічує прогалини й питання для уточнення.
3. Аналітик перевіряє опис, вносить уточнення та погоджує його.
4. Другий агент готує BPMN на основі погодженого AS-IS.

Мета — скоротити час підготовки опису та схеми процесу, зберігши контроль аналітика над змістом і переходом між етапами.
