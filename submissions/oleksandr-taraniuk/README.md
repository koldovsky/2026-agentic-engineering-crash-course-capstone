# Bible Reader — Oleksandr Taraniuk

Нативний macOS-додаток (SwiftUI) для читання Біблії офлайн: чотири переклади, пошук з морфологією, паралельний перегляд і «Порівняти», нотатки, ілюстрації до проповіді й чорнетки проповідей.

**Код:** <https://github.com/taran-7/bible-reader> (публічний репозиторій). Код лежить окремо, щоб зберегти історію: 210 комітів, 28 PR, прогони CI. Докази практик — це саме вони.

Опис практик і доказів — в описі PR.
